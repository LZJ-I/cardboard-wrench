# 纸盒扳手 · Cardboard Wrench

QQNT 的 Windows 离线安装与恢复工具。装插件前会自动备份，需要时可以恢复原版。

安装器内置 LiteLoaderQQNT 1.4.1 兼容修正版和可选插件。安装包已在 QQ `9.9.37-54395` 上完成只读检测，实际写入由安装器核验版本和补丁状态。

## 安装

1. 确认 Windows 已安装 QQ。解压发行包 `cardboard-wrench-2.1.0-windows.zip`，运行里面的 `install_windows.exe`。
2. 在安装器中检查 QQ 安装目录和插件数据目录。QQ 装在其他位置时，选中含有 `QQ.exe` 的文件夹。已有 LiteLoader 的用户使用原来的插件数据目录。
3. 点 **检测状态**，核对 QQ 版本、补丁状态和恢复能力。选择要装的插件，群清理助手和定点表情回应会自动带上 IPC 前置。
4. 从 Windows 托盘完全退出 QQ，再点 **安装 / 修复**。核对提示里的目录和插件，在 Windows 管理员权限提示里确认。
5. 看到安装完成后启动 QQ，在 **设置 → LiteLoader** 中找到插件。定点表情回应首次使用时，需先添加规则并打开总开关。

| 可选插件 | 用途 |
|---|---|
| 群清理助手 | 搜索群聊、保留重要群、批量退群、点击群名打开会话 |
| 防撤回·本地修订版 | 后台缓存图片、查看撤回记录、双击定位原会话。离线数据库依赖适用于 x64 和 x86 QQ |
| 定点表情回应 | 为指定群成员的新消息添加表情。真实发送效果仍需验证 |
| 插件市场 | 浏览和安装其他 LiteLoader 插件 |

安装界面默认勾选群清理助手和插件市场。已有插件数据、撤回记录和规则保留。需要排查启动时，可在安装器中使用 **安全模式**、**撤销上次操作** 或 **恢复原版 QQ**。

```text
3. 等安装器报告成功后检查插件清单和版本，告诉我实际装了哪些插件、备份位置，以及在 QQ 设置里从哪里打开。定点表情回应的群、成员和启用状态由我在插件页配置。
```

## 源码与构建

`group-cleaner/`、`anti-recall-repair/`、`target-reactor/` 分别是三款插件的源码。`installer/` 包含安装、恢复、界面和构建代码。源码构建与命令行参数见 [安装器说明](installer/README.md)。
